# Gymex for Gemini CLI

Ask Gemini about your own [Gymex](https://gymex.fitness/ai) training data — workouts, lifts, PRs,
recovery, program, nutrition, body weight and wearables. Read-only.

## Install

```bash
gemini extensions install https://github.com/coreyc0809/gymex-gemini-extension
```

Start `gemini`, run `/mcp auth gymex` (or just ask a question) and sign in with your Gymex account in
the browser window that opens. Then try:

- "How's my bench press progressing over the last 3 months?"
- "Am I recovered enough to train legs today?"
- "Did I hit my protein target this week?"

## Gemini app

In the Gemini app (personal Google accounts, supported regions): Settings → Connected apps → add a
custom app with `https://mcp.gymex.fitness/mcp`.

## Limits & privacy

Free Gymex members get 3 questions a day; Core 20, Premium 60, Pro Premium 200.
The connection is read-only. See [gymex.fitness/privacy](https://gymex.fitness/privacy#ai-assistants).
